# LiveKit Agents als volledige voice-pipeline

In plaats van zelf WebRTC, Voice Activity Detection en turn-detection/endpointing te bouwen, gebruiken we LiveKit Agents (Node.js, `@livekit/agents`) als de volledige realtime voice-pipeline: audio-in/uit, Silero VAD, een ingebouwd endpointing-model voor turn-taking, en plugbare STT/TTS-providers achter één `AgentSession`-abstractie. Dit dekt meteen een groot deel van de Type1-turn-taking-behoefte zonder extra werk. Het is een stuk lock-in — de hele spraakinteractie hangt aan deze library — maar het alternatief (zelf een realtime audio-pipeline met VAD en endpointing bouwen) is een veelvoud van het werk voor iets dat geen kernonderscheid van Animus is. Bijkomend voordeel voor fase 4: het robotje zit als "participant" in een LiveKit-room, waardoor een telefoon/webapp later kan meeluisteren of op afstand aansturen.
