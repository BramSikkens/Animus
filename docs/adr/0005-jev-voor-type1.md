# Jev voor Type1

Type1-taken (perceptie-filtering, emotielabel, intent-routering, nieuwsgierigheids-trigger) hebben geen taalgeneratie nodig — enkel een typed classificatie met een waarschijnlijkheidsscore. We kiezen Jev (TypeSafe's "System One Model") hiervoor in plaats van een goedkope LLM-call of een zelfgebouwde classifier. Reden: Jev is sub-100ms en extreem goedkoop ($0,042 per 1M input-tokens, output gratis) — een LLM-call zou zowel trager als duurder zijn voor iets dat toch neerkomt op een vaste set categorieën, en een eigen classifier zou training/onderhoud vergen die hier niet in verhouding staat tot de taak. Dit is de kern van de kostenbeheersing-strategie: alles wat in een vaste categorie past gaat via Type1, pas bij een positieve trigger komt Type2 in beeld.
