# Leeftijd = kalendertijd sinds geboorte

Het robotje's leeftijd kan op twee manieren gedefinieerd worden: kalendertijd sinds `born_at` (loopt door terwijl het uitstaat), of enkel actieve/aan-tijd (een soort uptime-teller). We kiezen kalendertijd. Dit sluit aan bij de kernmetafoor "een levend wezen dat slaapt maar blijft bestaan" — een uptime-teller zou het robotje eerder als toestel laten aanvoelen dan als wezen, wat tegen de visie van het project ingaat.
